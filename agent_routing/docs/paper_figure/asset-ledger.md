# Asset Ledger

## Exact Assets

- Style reference: local `topconf-handdrawn-rl-pipeline.png`, used only for
  visual measurement and palette extraction.

## Editable Primitive Icons

- Database cylinder: normalized task pool.
- Purple star glyph: trainable or learned LLM component.
- Rounded cards: data rows, advisor signals, actions, reward terms, and managers.
- Dashed rounded containers: stages and grouped components.
- Orthogonal arrow connectors: forward flows and recurrent policy loops.

## Approximations

- The reference's hand-drawn irregularity is approximated with Comic Sans MS,
  rounded primitives, sampled colors, and lightly dashed regions.
- Vendor logos are replaced by editable text names.
- The reference's decorative sparkles are reduced to one semantic model marker.

## Missing Assets

None required. The final draw.io artifact intentionally embeds no raster images,
external URLs, proprietary icons, or font files.
